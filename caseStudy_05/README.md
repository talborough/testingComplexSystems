# OTest

**A hands-on lab for testing Oracle DBMS software**

This project is part of [Case Study 5](https://TestingComplexSystems.com) from TestingComplexSystems.com. It is meant for learning how complex computer systems and software behave when things go wrong — not for everyday DBMS work.

---

## What is this?

Imagine you have several Linux computers running highly-available Oracle DBMS software and several more using that Oracle software.

**OTest** is a program that lets you:

1. Set up highly-available Oracle software on multiple computers
2. Start programs that **read and write files** on those computers
3. Let you **stress-test** the setup — reboot computers, swap roles, pause work, and more
4. **Check** that data stays correct and report problems if something breaks

Think of it like a science experiment: you build a DBMS-based test environment, run workloads on it, poke at it, and watch what happens.
