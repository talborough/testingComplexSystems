# OTest

**A hands-on lab for learning and testing Oracle DBMS software**

This project is part of [Case Study 5](https://TestingComplexSystems.com) described in TestingComplexSystems.com. It is designed to learn how complex computer systems and software behave when things go wrong.

---

## What is this?

Imagine you want to test several Linux computers running highly-available Oracle DBMS software and several more using that Oracle software. Or, imagine you just want to get your feet wet with Oracle, Linux, Azure and test platforms.

**OTest** is a program that lets you:

1. Set up highly-available Oracle software on multiple computers
2. Start programs that **read and write data** on those computers
3. Let you **stress-test** the setup — reboot computers, fail networks, pause work, and more
4. **Check** that data stays correct and report problems if something breaks

Think of it like a science experiment: you build a DBMS-based test environment, run workloads on it, poke at it, and watch what happens.
